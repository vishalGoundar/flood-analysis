1. Introduction

In January 2023, Auckland experienced record-breaking rainfall, followed two weeks later by Cyclone Gabrielle—two consecutive extreme weather events that caused widespread flooding, critical infrastructure damage, and community disruption. These events highlighted the growing vulnerability of New Zealand’s urban and natural systems to the increasing frequency and intensity of extreme rainfall events driven by global climate change (IPCC, 2022; NIWA, 2023). Understanding flood dynamics at both local and regional scales, and identifying the factors that govern infrastructure resilience, is therefore critical for effective emergency response, infrastructure planning, and long-term resilience building.

Traditional flood monitoring methods rely on in-situ observations and optical satellite imagery. However, these approaches are often hindered by limited spatial coverage, delayed reporting, and extensive cloud cover during storm events (Brakenridge et al., 2017). To address these operational constraints, this project utilizes Synthetic Aperture Radar (SAR) data—specifically from the Sentinel-1 satellite—as a reliable, all-weather alternative. Unlike optical sensors, SAR can penetrate cloud and rain, capturing surface conditions under all-weather and day–night conditions. Changes in SAR backscatter intensity can be used to detect standing water, surface roughness, and inundation extent, making it highly suitable for near-real-time flood mapping (Pulvirenti et al., 2020).

1.1 Project Aims and Deliverables

The primary aim of this project is to develop and validate a geospatial machine learning pipeline that fuses multi-source data—integrating SAR, optical (Sentinel-2), topographic, hydrological, and socioeconomic features—to inform flood resilience and infrastructure planning for the industry partner.

This report addresses the following specific objectives:

  1. Predictive Model Development: To develop and validate three complementary non-linear models: a Convolutional Neural Network (CNN) for detailed flood segmentation, Gradient Boosting (GB) Classifier and a Random Forest (RF) classifier for phase-based flood categorization, using engineered SAR and geospatial features.
  2. Factor Correlation Analysis: To perform localized correlation analysis (Spearman's ρ) between numerous geospatial factors and Traffic Volume across six diverse Areas of Interest (AOIs) to identify the dominant, non-uniform drivers of regional mobility and inform targeted infrastructure decisions.
  3. Resilience Planning: To utilize the validated flood model outputs and geomorphological criteria (e.g., Elevation, Slope) to strategically identify candidate Safe Zones for flood-resilient infrastructure placement.

A reproducible workflow built in Earth Engine and Python is published at github.com/vishalGoundar/flood-analysis, enabling easy integration and extension by the technical partner.

2. Methods

The methodology established a fully automated and reproducible flood detection pipeline, executed primarily within the Google Earth Engine (GEE) cloud environment for multi-source data integration, complemented by Python for sophisticated spatial augmentation and machine learning model training. The approach focused on training a robust model on the Auckland region's Cyclone Gabrielle data and rigorously testing its transferability to five other New Zealand Areas of Interest (AOIs).

2.1 Processing Workflow

The pipeline integrates dynamic satellite observations with static environmental and infrastructural layers to generate enriched training samples for flood classification. Implemented primarily in Google Earth Engine (GEE) and Python, the workflow produces over 20 predictor variables per Sentinel-1 pixel, enabling robust machine learning across diverse AOIs.

2.3 Feature Engineering and Preprocessing

2.3.1 Dynamic Feature Derivation

Sentinel-1 Preprocessing: Ground Range Detected (GRD) imagery (Interferometric Wide mode, IW) was processed using GEE’s standard pipeline (thermal noise removal, radiometric calibration, and Terrain Correction). The VV and VH bands were converted to decibels (dB) and combined with the angle band. The derived features VV/VH ratio and VV−VH difference were computed due to their sensitivity to surface water and roughness (Pulvirenti et al., 2020). Antecedent Rainfall: The CHIRPS Daily Rainfall dataset was used to calculate the 7-day rolling sum (Rainfall_7d) preceding each SAR acquisition, capturing short-term soil moisture conditions.

2.3.2 Static Feature Augmentation

Static environmental predictors (e.g., NDVI, NDBI, dw_class, Elevation, Slope) and hydrological metrics (DistRiver) were extracted from their respective source products.

2.3.3 Python Spatial Augmentation

Infrastructure features (DistWastewater, DistFacility, WastewaterDensity, FacilityDensity) were computed in Python using vector assets. Euclidean distances were calculated efficiently via KDTree spatial indexing to determine proximity. Density metrics were derived by counting or summing infrastructure segments within a 3 km radius for each sample point.

2.3.4 Ground Truth Generation

A two-step, rule-based logic was applied to assign the binary floodlabel to each sample point:

  1. Permanent Water Masking: A binary flag is_permanent_water was created using terrain conditions (Slope<2∘ and DistRiver<100 m) combined with the JRC Global Surface Water occurrence layer (>90% persistence). These areas were masked from the flood classification.
  2. Flood Logic: Pixels acquired during or post-cyclone were labelled floodlabel=1 if they met a Primary (strict) or Fallback (relaxed) set of thresholds on SAR indices (VV−VH, VV/VH), NDVI, and DistRiver.

2.4 Machine Learning Methodology

The enriched dataset, containing over 20 predictors, was split into stratified 80%/20% Training/Test sets.

2.4.1 Data Preparation Pipeline

A consistent sequential preprocessing pipeline was implemented for all models:

  1. Missing Value Imputation: All missing features were handled using Median Imputation (SimpleImputer).
  2. Class Balancing: The severe imbalance between the 'No Flood' and 'Flood' classes in the training set was addressed using the Synthetic Minority Oversampling Technique (SMOTE) to generate synthetic samples for the minority class.
  3. Feature Scaling: Features were then Standardized (StandardScaler) based only on the SMOTE-resampled training data.

2.4.2 Model Training and Optimization

Three distinct classification models were trained and compared, all using the preprocessed Auckland training data:

  1. Random Forest (RF): Optimized using Randomized Search Cross-Validation (n_iter=5 for efficiency) with Macro F1-Score as the optimization metric to ensure balanced performance across both classes. The classifier included a class_weight="balanced" setting.
  2. Deep Learning (MLP): A Feedforward Neural Network was built with three dense layers, utilizing Batch Normalization and Dropout (0.3) for regularization. Training was performed with the Adam optimizer and binary\_crossentropy loss, with an optimal learning rate of 0.0005

determined via preliminary search.

  1. Gradient Boosting Machine (GBM): Optimized using RandomizedSearchCV with Macro F1-Score.

2.4.3 Evaluation and Transferability Assessment

Model performance was assessed using the Classification Report (Accuracy, Precision, Recall, F1-Score) and Confusion Matrices. The core evaluation focused on Transferability: the Auckland-trained models were deployed without modification onto the five external AOIs (Warkworth, Hawkes Bay, etc.). Permutation Importance was calculated for the RF and GBM models on each external AOI to identify the features most critical for prediction in each unique geographic context.

4. Discussion

The deployment of a multi-source geospatial analysis pipeline—fusing Synthetic Aperture Radar (SAR), topographic, hydrological, and socioeconomic data—successfully generated localized insights into the factors influencing traffic volume and flood resilience across multiple Areas of Interest (AOIs). This section analyzes the performance of the implemented methods, assesses the limitations encountered, and proposes a pathway for the project's operational transition.

4.1 Strengths

The project's primary strength lies in its holistic data integration and the development of a high-accuracy predictive model for extreme event assessment.

  • Novel Data Fusion: We successfully integrated diverse, complex datasets, including Sentinel-1 SAR backscatter (VV, VH, Ratio, Difference) and derived products (NDBI, NDVI), with ground truth traffic data, establishing a comprehensive feature space for analysis. This multi-sensor approach enhances the reliability of insights beyond single-source limitations.
  • Identification of Key Predictors: The correlation analysis proved highly effective in identifying strong, localized linear relationships. For example, Population Density showed an extremely strong positive correlation with traffic volume in Dargaville (ρ=0.81), confirming its dominant influence on mobility in that specific region and allowing stakeholders to prioritize key planning features.
  • Predictive Power for Flood Mitigation: The Gradients Boosting (GB), Random Forest (RF) and Convolutional Neural Network (CNN) model's, trained on Auckland data, achieved a high-level accuracies of 97.01%, 96.51%, and 93.85% in flood prediction. This validated model's output was then instrumental in identifying geomorphologically constrained candidate Safe Zones (Elevation ≥10m, Slope ≤ 10°), directly contributing a data-driven layer to flood-resilient infrastructure planning.

4.2 Weaknesses

Despite these strengths, the analysis revealed several limitations stemming from data characteristics and the generalized modeling approach, which pose immediate challenges for widespread deployment.

  • Non-Uniformity and Site-Specificity: The majority of correlations were highly AOI-dependent, demonstrating a major weakness in creating a single, nationally generalizable model. For instance, Distance to Wastewater showed a strong negative correlation in Waimauku (ρ=−0.68) but a weak positive correlation in Warkworth (ρ=0.17). This lack of uniformity necessitates the development of localized models, as a single global model risks significant predictive errors when transferred to structurally distinct areas.
  • Weak Linear SAR Explanatory Power: Most raw SAR-derived variables (VV, VH, Difference, Ratio, Angle) exhibited negligible to weak linear correlation with traffic volume (e.g., VV-VH Difference max ρ was -0.24). This suggests that the raw backscatter measurements have limited linear explanatory power for traffic and may require non-linear transformation or combination with other features to become useful predictors, or that their primary value lies in non-linear classification tasks (like flood detection) rather than linear volume prediction.
  • Data Sparsity and Transferability Loss: Data quality issues, such as missing Wastewater Density data for Dargaville, limit model robustness in certain regions. Furthermore, the GB, RF, and CNN models experienced a significant drop in accuracy when transferred to other AOIs (e.g., down to 81.40%, 80.62%, and 68.02% in Dargaville), highlighting the intrinsic difficulty of model generalization across diverse geographic and structural environments.

4.3 Further Work

To evolve this project into a robust, scalable, and deployable system for the industry partner, the following areas should be prioritized, directly addressing the limitations identified above:

  1. Exploration of Non-Linear Modeling: The observed non-uniformity and weak linear correlations suggest that the underlying relationships are complex and non-linear. The existing non-linear models (GB, RF, CNN) should be further refined by exploring advanced ensemble techniques in Gradient Boosting Machines (GBMs) and Deeper Network Architectures (DNNs), to better capture the synergistic effects between variables and potentially increase the predictive value of SAR data.
  2. Temporal Analysis Integration: The current analysis uses a static snapshot of traffic volume (Feb 2023). Incorporating time-series analysis using daily or hourly traffic counts would allow the model to account for temporal confounding factors (e.g., peak-hour congestion, seasonal variations, or post-event traffic dynamics), significantly improving predictive fidelity and operational relevance.
  3. Refined Feature Engineering: Investigate the creation of non-linear indices and interaction features that combine SAR and topographic data (e.g., SAR backscatter normalized by local slope or road orientation). This is a critical step to extract more physically meaningful and robust predictors from SAR products that currently show weak individual linear performance.
  4. Hyper-localized Model Deployment: To overcome the challenge of transferability loss, focus on developing a cluster of localized models. This approach involves training distinct models for AOIs that share similar characteristics (e.g., high population/urban AOIs vs. rural/agricultural AOIs) to maximize predictive accuracy for regional deployment.

5. Summary of Flood Prediction Model Analysis

The analysis involved training Random Forest (RF), Deep Learning (MLP), and Gradient Boosting (GBM) models on Auckland flood data and evaluating their performance across five other New Zealand regions (AOIs), focusing on transferability and key feature importance.

5.1 Model Training and Optimization

  • Optimal Hyperparameter Search: For the Random Forest and Gradient Boosting models, the performance metrics (Macro F1-Score and Accuracy) consistently improved with more search iterations, with n_iter=50 yielding the best result on the Auckland test set. The final analysis used n_iter=5 as a balance of speed and performance (Macro F1: 0.9651 and 0.9701).
  • Optimal Learning Rate (MLP): The Deep Learning (MLP) model achieved its highest validation accuracy (0.942) on the Auckland test set using a learning rate of 0.0005.
